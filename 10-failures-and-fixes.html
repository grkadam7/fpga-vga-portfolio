01Cycle 1 — Output clips when the gain is too high for the input
FieldEntry
SymptomOutput flattens (clipping) in simulation when a high gain code is used with a larger input — observed side by side with the unclipped case at a lower gain.
Test performedLTspice run of the complete model at the same input with two gain settings; input and output waveforms compared against the XADC input limit.
Root causeInput amplitude × programmed gain exceeded the linear output range / the 1 V ADC input limit — a fixed relationship, not a component fault.
CorrectionGain must fall as input rises: the gain-selection rule (switch down before the output clips), which is the reason the artefact is variable-gain at all.
Re-measured[ PENDING — hardware: raise the input at each code until the clipping criterion from WS7 · B.1 is met, record the max input before clipping ]
LearningA calculated gain is not a usable gain: the usable setting depends on the input amplitude and the destination range, not on the amplifier alone.
