01Calculation card 1 — Gain equation and the four gain values FR2
FieldEntry
DecisionFour discrete non-inverting gain levels ×2, ×3.2, ×5.7 and ×11, selected by a 2-bit code (S1, S0) from the Artix-7 FPGA driving a CD4052 analog multiplexer.
Options considered1. Fixed-gain amplifier — set aside: limited dynamic range, small load-cell signals under-use the ADC range while large ones saturate the amplifier and the ADC.
2. Op-amp with feedback resistors switched by an analog multiplexer — chosen: simple, reliable, widely used for sensor signal conditioning, and all four levels follow from one 2-bit code.
3. Digital potentiometer / 4. Dedicated PGA IC — see page 3 for the reasons they were set aside.
FR servedFR2 (four digitally selectable gains), supporting FR1 (useful level for the XADC across 0–5 kg)
EquationAv = 1 + RF / Rin  (non-inverting amplifier)
ValuesRin = 1 kΩ fixed; RF selected by the CD4052.
Result
