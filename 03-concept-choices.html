01Alternatives considered

At least three alternatives were compared before the concept was chosen. Rejected options stay on this page with the reason they were set aside.

Option 1 — Fixed-gain amplifier

Sketch: [ PENDING — upload sketch ]
One non-inverting stage with a fixed feedback network.

Set aside because: limited dynamic range — small load-cell signals under-use the ADC range while large ones saturate the amplifier and the ADC; no adaptation to the varying input amplitude.

Option 2 — Op-amp with feedback resistors switched by an analog multiplexer Chosen

Sketch: [ PENDING — upload schematic sketch ]
Non-inverting op-amp stage whose feedback resistor RF is selected by a CD4052 under FPGA control (S1 S0).

Chosen because: simple, reliable and widely used for sensor signal conditioning; all four gain levels follow from one 2-bit code; gain is predictable from first principles (Av = 1 + RF/Rin), so it can be calculated, simulated and verified.
